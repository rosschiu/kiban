Notification module API (1.0.0)

Download OpenAPI specification:

The notification module's HTTP API. All paths live under /api/notification with the major version in the path (/v1). Outbound delivery (webhook POST, SMTP) is at-least-once, never exactly-once or at-most-once. Every outbound delivery carries a stable per-job idempotency key (X-Kiban-Delivery-Id on webhook POSTs; Message-Id on SMTP) so receivers can dedupe a redelivery of the same job.

Liveness probe. Served on the service's own listener, not under `/api/<module>`.

Authorizations:
bearerAuth

Responses

/health
